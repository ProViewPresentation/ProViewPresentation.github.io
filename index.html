01 • ARCHITECTURAL FOUNDATION

How ProView Works

ProView operates on a decoupled permission and dual-workspace architecture, separating deep structural management from real-time Sunday-morning execution.

01

The Database Core

All songs, media files (photos, loops, background videos), Bible translations, and sermon elements are stored in a centralized, cloud-synced, or local database.

02

The Service Organizer

Services are built as chronological "Collections" (e.g., Sunday Morning Traditional, Youth Night, Midweek Bible Study). Items can be reordered and grouped effortlessly.

03

The Live Engine

When "Go Live" is clicked, ProView transitions into a high-performance rendering engine that outputs customized feeds to main projection screens, stage confidence monitors, and NDI streams.

02 • DEDICATED WORKSPACE PAGES

Two Separate Workspaces for Zero Sunday Panic

To ensure Sunday services run without a hitch while keeping the main platform secure, ProView is divided into two separate workspace pages.

WORKSPACE A • PREPARATION

The Admin Page (The Control & Creation Hub)

This is where 90% of the heavy lifting, preparation, and template designing happens ahead of time during the week.

  • What you do here: Import and edit new songs, manage the master media library, configure global slide themes, set up default font sizes, manage user permissions, and map out upcoming service collections weeks in advance.
  • Who uses it: Worship pastors, media directors, and tech leads during the week.
Go to Separate Admin Page →
WORKSPACE B • LIVE EXECUTION

The Project Operator Page (The Live Execution Hub)

Designed for absolute simplicity, speed, and clean visibility during a live service. It gives the volunteer or projectionist complete control over the active service playlist.

  • What you do here: Run the live service by clicking through slides, songs, and announcements.
  • Mini-Editing Capabilities: Adjust text density on overflowing slides, split slides via Smart Reflow, swap a background photo, or append a last-minute slide item right from the operator deck without corrupting master templates.
