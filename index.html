1. How ProView Works

ProView operates on a decoupled permission and dual-workspace architecture. It separates deep structural management during the week from real-time Sunday-morning execution.

01

The Database Core

All songs, media files (photos, loops, background videos), Bible translations, and sermon elements are stored in a centralized, cloud-synced, or local database powered by BreadBackend.

  • ✦ Centralized Song & Lyric Repository
  • ✦ Cloud-Synced Media Assets (Up to 50MB/file)
  • ✦ Multi-Translation Scripture Library
  • ✦ Reusable Sermon Templates & Themes
02

The Service Organizer

Services are built as chronological "Collections" (e.g., Sunday Morning Traditional, Youth Night, Midweek Bible Study). Items can be dragged, dropped, and grouped effortlessly.

  • ✦ Chronological Service Playlists
  • ✦ Nested Multi-Part Sermon Folders
  • ✦ Instant Reordering & Grouping
  • ✦ Weeks-in-Advance Service Planning
03

The Live Engine

When "Go Live" is clicked, ProView transitions into a high-performance rendering engine that outputs customized feeds to main projection screens, confidence monitors for the stage, and direct NDI/video streams for online viewers.

03 • Dual-Workspace Architecture

3. The Two Core Pages: Admin Page vs. Project Operator Page

To ensure Sunday services run without a hitch while keeping the main platform secure, ProView is divided into two primary workspaces. Click into either workspace below to experience it live.

A • THE CONTROL & CREATION HUB

The Admin Page

This is where 90% of the heavy lifting, preparation, and template designing happens ahead of time.

  • ✦
    What you do here: Import and edit new songs, manage the master media library (photos, videos, backgrounds), configure global slide themes, set up default font sizes, manage user permissions, and map out upcoming service collections weeks in advance.
  • ✦
    Who uses it: Worship pastors, media directors, and tech leads during the week.
  • ✦
    Master Template Protection: Changes made in the Admin Hub define the canonical database synced with BreadBackend.
5 Deep Preparation Modules
B • THE LIVE EXECUTION HUB

The Project Operator Page

Designed for absolute simplicity, speed, and clean visibility during a live service. It gives the volunteer or projectionist complete control over the active service playlist.

  • ●
    What you do here: Run the live service by clicking through slides, songs, scripture readings, and announcements with zero visual clutter.
  • ●
    Mini-Editing Capabilities: Even though the operator shouldn't mess up master templates, they have on-the-fly micro-editing power. If text overflows on a slide during a live sermon, the operator can instantly adjust text density/amount on that specific slide, swap out a background photo, drag in an emergency video clip, or append a last-minute slide item right from the operator deck without breaking the presentation flow.
